# AI 工作流触发指南

> 本文是 `AGENTS.md`「AI 工作流 → 触发短语」的详细说明。规则文件保持精简，完整解释与例子存于此。

## 触发方式一：触发短语（最明确）

| 你说 | 执行 |
|---|---|
| "消化一下 XXX" | 对来源走完整 Ingest |
| "XXX 整理入库"、"存进知识库" | 写入 vault 并联动更新 |
| "清空 quicknote / 收件箱" | 批量消化待处理条目 |
| "这篇文章整理入库"（附链接） | 抓全文 + 消化 + 归档 |
| "把刚才的分析/结论归档" | Query 归档：写回 wiki + 更新引用 + 记 log |
| "检查/验证知识库" | Lint 健康检查 |

## 触发方式二：隐性触发（意图暗示入库）

- 贴一段内容 + "记一下这个" / "留着以后看"
- "最近剪藏了些文章，帮我整理"（新文件出现是来源信号）
- "学完了 XXX，帮我沉淀一下"

## 触发方式三：不触发（纯问答）

- "这篇文章讲了什么？" → 只回答，不落库
- "A 和 B 有什么区别？" → 即时回答；结论有价值时询问是否归档（Query）
- "只是问问、不用存" → 明确不碰知识库

## 四个例子

### 例 1 · 对话内容入库

> 你："刚才聊的 QMT 策略整理一下，存到个人那边"

执行：确认要点 → 在 `06.Personal/量化/` 写笔记 → 更新 `06.Personal/MOC.md` → 记 log → push。

### 例 2 · 清收件箱（适合批量）

> 你："清空 quicknote"

执行：读 `quicknote.md` unread 条目 → 逐条确认归属 → 写入主题笔记 → 从 quicknote 移除 → 更新 MOC → 记 log。

### 例 3 · 外部文章

> 你："https://… 这篇消化进知识库"

执行：抓全文 → 确认要点 → 写摘要笔记 → 更新 MOC 与相关实体页 → 记 log。

### 例 4 · 真实案例（llm-wiki）

- "帮我总结 llm-wiki 内容" → 只总结，未入库（纯问答）
- "保存中文版的工作流总结…" → 完整 Ingest：新建 [[03.Engineering/Common_Area/AI/LLM-Wiki-中文实践指南|LLM Wiki 中文实践指南]]、更新 `AI/MOC.md`、记 log、推送
- "同步到得到知识库" → 额外平台同步动作

## 提高触发准确率的小技巧

1. 入库时**同时给素材 + 意图**："这是我找到的资料（贴内容），消化进 02.Domain"
2. 只想要答案时加一句"只是问问，不用存"
3. 批量素材先放收件箱 `quicknote.md`，再一句话"清空收件箱"
4. 意图含糊时（只贴内容无指令），会被先问一句"要入库吗"
