# 98.Raw — 原始来源层

本目录是 LLM Wiki 三层结构中的**原始来源层**（raw sources）：文章、报告、转录、论文、数据集说明等**未经加工的真相来源**。LLM 只读，wiki 层（`00.`–`06.` 的笔记与 `MOC.md`）才是 LLM 生成和维护的内容。

## 三条铁律

1. **只读**：LLM 不修改、不重命名、不删除本目录下的文件。
2. **不做规范批量处理**：本目录文件豁免五键 frontmatter、tag、H1 等 wiki 规范，不参与批量补全；原文什么样就什么样。
3. **更正写在 wiki 层**：发现原文有误或已被新来源推翻，在对应主题笔记里标注「已被 XX 取代」，而不是改原文。

## 放什么 / 不放什么

| 放这里 | 不放这里 |
|---|---|
| 网页剪藏、PDF/文章正文、播客或会议转录、论文、外部报告的原始文本 | 自己的理解、摘要、对比、结论（→ `00.`–`06.` 主题笔记） |
| 用户直接提供的原始素材（贴进来的全文） | 临时速记、待办、灵感碎片（→ 根级 `quicknote.md`） |
| 来源的元信息文件（如 `xxx.meta.md`，记录来源 URL/日期） | 图片等附件（→ `99.Attachments/`，保持全库附件统一存放） |

## 命名建议（跨平台，避免空格与特殊字符）

- 推荐 `YYYY-MM-DD-简短标题.md`（如 `2026-10-09-llm-wiki.md`），便于排序与追溯；
- 一个来源一个文件；同一来源的多次抓取用日期区分，不覆盖旧文件。

## Ingest 如何消费本目录

1. 读 `98.Raw/` 中的原始来源，与用户确认要点与归属；
2. 在 `00.`–`06.` 对应目录写主题笔记，并在 frontmatter 的 `source` 登记原始来源路径（如 `98.Raw/2026-10-09-llm-wiki.md`）；
3. 更新对应 `MOC.md` 与受影响页面；
4. **原始来源保留不动**——与 `quicknote.md` 的速记条目（消化后移除）相反。

> 规则定义见根级 [`AGENTS.md`](../AGENTS.md)；本目录只对**新增来源**生效，历史上已写入 wiki 层的原文就地保留（2026-10-09 决定）。
