# 风热

**辨证要点：发热重、恶寒轻**

| 维度 | 风热表现 |
|---|---|
| 恶寒 / 发热 | 发热重、恶寒轻，有汗或少汗 |
| 头身 | 头胀痛，肢体酸痛较轻 |
| 鼻咽 | 鼻塞、流黄涕；**咽喉红肿疼痛明显** |
| 咳嗽咳痰 | 痰黄、黏稠 |
| 口渴 | 口渴喜冷饮 |
| 舌脉 | 舌边尖红、苔薄黄，脉浮数 |

**治法**：辛凉解表（疏风清热），兼化湿解表或清热解毒。

**宜用中成药**：连花清瘟胶囊或颗粒、金花清感颗粒、疏风解毒胶囊、宣肺败毒颗粒、清肺排毒颗粒、热炎宁合剂（颗粒）、银翘解毒颗粒、蓝芩口服液、复方芩兰口服液、痰热清胶囊、双黄连口服液、抗病毒口服液等。

> 与 [[05.Health/中医/风寒|风寒]] 的鉴别见 [[05.Health/中医/风热vs风寒|风热 vs 风寒]]。两者症状有重叠项（乏力、咳嗽、肌肉酸痛都可能出现），**关键看恶寒与发热孰重、口渴与否、痰涕颜色**——只按重叠症状判断会串证。以上为常见的辨证要点，用药请遵医嘱。
