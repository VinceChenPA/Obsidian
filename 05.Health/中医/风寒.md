# 风寒

**辨证要点：恶寒重、发热轻**

| 维度 | 风寒表现 |
|---|---|
| 恶寒 / 发热 | 恶寒重、发热轻，无汗 |
| 头身 | 头痛、肢体酸痛明显 |
| 鼻咽 | 鼻塞、流清涕；咽痒，咽痛不突出 |
| 咳嗽咳痰 | 痰白、清稀 |
| 口渴 | 口不渴，或渴喜热饮 |
| 舌脉 | 舌苔薄白，脉浮紧 |

**治法**：辛温解表（疏风散寒）。

**宜用中成药**：感冒清热颗粒、荆防颗粒、正柴胡饮颗粒、清解退热颗粒等。

> 与 [[05.Health/中医/风热|风热]] 的鉴别见 [[05.Health/中医/风热vs风寒|风热 vs 风寒]]。两者症状有重叠项（乏力、咳嗽、肌肉酸痛都可能出现），**关键看恶寒与发热孰重、口渴与否、痰涕颜色**——只按重叠症状判断会串证。以上为常见的辨证要点，用药请遵医嘱。
