# 🚗 云南亲子自驾行程 · 佛山出发（蔚来 ES8 纯电版）

**车辆：** 蔚来 ES8（102kWh，900V 超快充）
**日期：** 2026.7.22（三）— 7.31（五），共 10 天
**人员：** 两大两小（亲子）
**起点：** 佛山
**路线：** 佛山 → 南宁 → 昆明 → 大理 → 丽江 → 昆明 → 南宁 → 佛山
**总里程：** ~3,000km

## ⚡ 充电总结

| 项目 | 数据 |
|------|------|
| 全程充电次数 | ~8 次 |
| 单次充电时长 | 15-25 min |
| 总充电等待 | ~3h（均与休息/吃饭重叠） |
| 总电费 | ~600 元（高速快充 ~1.5 元/度） |

**沿途充电站分布：**
- G80 广昆高速：梧州/贵港、百色、富宁/砚山
- 楚大高速：楚雄服务区
- 各城市酒店/民宿：夜间慢充
